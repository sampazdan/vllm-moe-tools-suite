# Aider Polyglot Python expansion notices

This five-task expansion contains Python exercise instructions, starter files,
tests adapted to an isolated RPC verifier, and exemplar implementations from
the Aider Polyglot conversion in `laude-institute/harbor-datasets` at commit
`f30b14415dd733c83627204bad0af69a89ceb46f`. The pinned Harbor adapter at
`harbor-framework/harbor` commit
`488af1b12b3b728b9364ab5e1bb663bd3e0ae643` attributes those components to
the Aider Polyglot Benchmark and the Exercism Python track.

The Exercism Python track and Exercism problem specifications are distributed
under the MIT License. The Harbor adapter and harness are distributed under
the Apache License 2.0. The verifier isolation and application-specific pack
format are modifications made for MoE Atelier. This pack is not an official
Aider leaderboard cohort.
